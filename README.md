# ATLAS UI Kit — Практическая работа №5

## Архитектура токенов

Проект использует трёхуровневую систему дизайн-токенов:

### Уровень 1: Примитивы
Базовые значения без контекстной роли:
- `--base-blue-700: #1853a4` — базовый синий цвет
- `--space-4: 1rem` — базовый отступ
- `--font-size-base: 1rem` — базовый размер шрифта

### Уровень 2: Семантические роли
Назначение значения в интерфейсе:
- `--color-primary: var(--base-blue-700)` — основной цвет действия
- `--color-text: var(--base-slate-950)` — основной текст
- `--color-error: #a12735` — цвет ошибки

### Уровень 3: Компонентные токены
Роль в конкретном компоненте:
- `--button-bg-primary: var(--color-primary)` — фон основной кнопки
- `--button-height: 2.75rem` — высота кнопки
- `--alert-padding: var(--space-4)` — отступ внутри уведомления

### Пример цепочки
--base-blue-700 → --color-primary → --button-bg-primary → .button--primary { background }

## Темы

Реализовано три режима:
- **Auto** — определяется настройками ОС через `@media (prefers-color-scheme: dark)`
- **Light** — ручная светлая тема через `data-theme="light"`
- **Dark** — ручная тёмная тема через `data-theme="dark"`

Приоритет: ручной выбор > системная настройка.

## Компоненты

- **Кнопки**: primary, secondary, ghost + состояния hover/active/focus/disabled
- **Поля**: default, focus, disabled, invalid (aria-invalid="true")
- **Уведомления**: info, success, error, warning

## Самостоятельная часть

### Компактный режим
Переопределено 6 компонентных токенов:
- `--button-height: 2.25rem` (вместо 2.75rem)
- `--control-height: 2.25rem`
- `--button-padding-inline: var(--space-3)`
- `--control-padding-inline: var(--space-3)`
- `--component-gap: var(--space-2)`
- `--alert-padding: var(--space-3)`

### Предупреждение
Добавлено 4-е уведомление warning с ролями:
- `--color-warning: #8a4b00`
- `--color-warning-bg: #fff6e5`

## Ответы на вопросы

**а) Почему плотность задаётся компонентными токенами?**
Компонентные токены (`--button-height`, `--control-padding-inline`) используются во всех компонентах через `var()`. Переопределив их один раз в `:root[data-density="compact"]`, мы меняем размеры всех кнопок и полей одновременно, без дублирования CSS-правил.

**б) Почему тёмная тема не должна хранить прямые цвета внутри .button?**
Если в `.button--primary` написать `background: #192536`, то при смене темы кнопка не изменится. Вместо этого кнопка использует `var(--button-bg-primary)`, который ссылается на `--color-primary`, который переопределяется в тёмной теме. Так кнопка автоматически адаптируется к теме.
